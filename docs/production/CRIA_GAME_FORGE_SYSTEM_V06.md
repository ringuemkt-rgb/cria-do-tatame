# Cria Game Forge v0.6

**Status:** SUPERSEDED  
**Successor:** [`CRIA_GAME_FORGE_SYSTEM_V1.md`](CRIA_GAME_FORGE_SYSTEM_V1.md)

This document is retained as historical context only. It no longer governs agent orchestration. The active system is capability-based and provider-independent.

## Historical mission

Construir o sistema unico de producao do Cria do Tatame: do design da tecnica ate sprite, Godot, IA de rival, carreira persistente e teste jogavel.

## Historical flow

```txt
ideia ou tecnica
-> ficha canonica
-> ficha de gameplay
-> ficha biomecanica
-> keyframes
-> sprite request
-> manifest de atlas
-> dados JSON
-> scripts Godot
-> teste e QA
```

The useful principles above are preserved in v1, but v1 additionally formalizes capability detection, tiered execution, tool/license routing, Visual Foundry, Sprite Forge, paired BJJ, world/map production, CI and physical-device release gates.
