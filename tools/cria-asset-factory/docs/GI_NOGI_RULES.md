# GI versus NO-GI

GI uniforms: off-white #EDE6D6 or blue #1E3A5F. NO-GI: black rashguard + fictional faction token + shorts. Build distinct input frames, no recolor claim. Collar/sleeve grips require GI clothing; NO-GI must use plausible non-gi contact. Keep one clothing mode per frame unless the narrative explicitly authorizes an outfit change. Five fingers; occluded grips require manual evidence.
