# Sprite Forge — camada offline

Camada de integração documental para `0x0funky/agent-sprite-forge`, pinada no manifesto local.

- não há código upstream vendorizado;
- instalação e execução ficam fora do runtime;
- chroma padrão: magenta `#FF00FF`;
- fringe magenta reprova QA;
- BJJ pareado final nunca nasce nem é aprovado apenas por este caminho;
- todo output permanece candidato até licença, QA e gate humano.

O pin evita depender silenciosamente da `main` mutável do projeto externo.
