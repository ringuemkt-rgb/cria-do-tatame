# Changelog

## v1.0.0 — Visual Foundry

- Adicionada a camada `tools/visual_foundry/` para fabricação visual 3D → sprite sem alterar o runtime 2D do jogo.
- Adicionado perfil canônico em `data/visual/visual_foundry_profile_v1.json` alinhado ao manifesto visual v02.
- Adicionado registro auditável de ferramentas open-source candidatas e preferenciais.
- Adicionado gerador determinístico de fila para personagens, técnicas pareadas, arenas e UI.
- Adicionado renderizador Blender headless com câmera ortográfica e saída RGBA.
- Adicionados contratos de proveniência, identidade, escala, pivô, sincronização de técnicas, Sprite Forge, integração Godot e performance mobile.
- Adicionados testes unitários e workflow GitHub Actions dedicado.
- Documentada a prioridade de produção do vertical slice Ruan × Davi antes da expansão horizontal do elenco.
